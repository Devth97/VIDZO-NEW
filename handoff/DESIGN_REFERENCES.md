# Public design research

Consulted 25 November 2026. Inspiration only: no copied designs/assets/UI source, no authenticated competitor audit, no Figma/Penpot prototype or buyer test completed.

| Reference | Application |
| --- | --- |
| [Canva ad creation](https://www.canva.com/create/ads/) | Familiar creation entry, clear action and visual context, in VIDZO's own branding. |
| [NN/g progress indicators](https://www.nngroup.com/articles/progress-indicators/) | Actual job stages, saved work and return path; never invented provider percentages. |
| [Laws of UX: goal-gradient effect](https://lawsofux.com/goal-gradient-effect/) | Genuine milestones and visible approvals, without manufacturing steps. |
| [shadcn/ui](https://github.com/shadcn-ui/ui) / [MIT license](https://github.com/shadcn-ui/ui/blob/main/LICENSE.md) | Accessible composable component reference. Current implementation uses native HTML/dialog, not copied shadcn source. |
| [Mobbin](https://mobbin.com) | Suggested for future audit in the source design spec; authenticated catalogue was not inspected. |

Magic UI/Astryx were mentioned in the source documents but not adopted. Avoid two full competing component systems. Current warm light/olive UI is a draft needing browser/contrast/user testing.

Conversion choices: one primary action, draft/sample exploration before spending, actual saved milestones, quote/native resolution/spend cap before consent, targeted revisions, truthful failure treatment. No fake urgency/social proof or guaranteed outcomes.
